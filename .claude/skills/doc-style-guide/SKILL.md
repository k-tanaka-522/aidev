# doc-style-guide（文書スタイル規約）

> 版数: M0雛形（実装対象: docs/v2/02_実行基盤アーキテクチャ.md 9.2節、4.2節。`.claude/docs/40_standards/`の後継の一部）
> `user-invocable: false` は設計書5.1節が定める本来の値（自動参照Skillのため、ユーザーが明示的に呼ぶものではない）。

## 責務

文書ヘッダー・語調・構成規約を定める。`生成区分`必須フィールドを含む（値は03文書8.4節と統一、9.2節）。

## 呼び出し元・連携先

- 呼び出し元: `reverse-doc`系（自動、`paths`相当の発火を想定。具体的な発火条件はM1で確定）

## `生成区分`フィールド（MUST、9.2節）

`doc-style-guide`の文書ヘッダーテンプレートに`生成区分`を必須フィールドとして追加する。値は次のいずれかとする。

- `実装反映(as-built)`
- `事前設計(前倒し)`（要件定義前倒しモード選択時の前倒し要件定義書のみ）
- `手動作成`

`doc-header-guard.js`（7.3節#4）がこのフィールドの有無と値の妥当性を機械チェックする。

## 検査対象範囲（版1.4で確定、9.2節・7.3節#4）

検査対象は`docs/0[2-7]_**`に限定する。`docs/00`・決定ログ・`docs/v2/*`は対象外とする（旧版の不備の是正）。

## reverse-doc経由の実行時マーカー（9.2節）

`reverse-doc` Skill経由で生成されたことを示す実行時マーカーを用いて、`reverse-doc`を経由せず直接`docs/02〜07`に書き込まれたファイルを識別し警告する。**この識別方式は更新漏れへの脆弱性を持つことに注意する**。
