# doc-link-check（文書間リンク検査）

> 版数: M4実装（実装対象: docs/v2/02_実行基盤アーキテクチャ.md 9.6節、
> docs/v2/03_成果物体系定義書.md 8.2節）

## 責務

03文書8.2節が要求するリンク切れ検知を実装する。**本プロジェクトで参照切れが
（02文書改訂履歴に記録されているだけで）複数回発生しているため（版1.7指摘7の
`github_actions.md`外部参照切れ等）、参照先の実在検査は重要である。**

## 手順（MUST）

```
1. docs/配下の全Markdownをgrepし、[...](...)形式の相対リンクを抽出する
2. リンク先パスが実在するかを確認する（実在しなければ「参照切れ」として報告）
3. ファイル名パターン（{項番}-{連番}_*.md）と本文中の項番言及
   （「◯◯（03-04）を参照」等）を突合し、項番のみで実ファイルへのリンクが
   張られていない箇所を検出する（「未リンク言及」として報告）
4. 検出結果を00-13_課題管理表.mdへ登録する（MUST）
```

## Routineとしての定期実行（12章、四半期ごと）

02文書12章のRoutines機構が稼働するのはM5以降である。M4時点では本Skillを
`orchestrate`から明示的に呼び出す運用（手動トリガ）に留め、Routineへの登録は
M5のRoutines機構実装時に行う（`artifact-emptiness-guard.js`が採った「PostToolUseを
正としRoutineを補助にする」段階移行と同型のアプローチ、02文書7.3節#8参照）。

## 実行方法

```bash
node .claude/skills/doc-link-check/scripts/check-links.js --dir=docs
```
