# サブエージェント定義

## 1. 概要

### 1.1 目的

各サブエージェントの役割、責務、参照・更新するリソースを定義する。

### 1.2 設計方針

```
1. 専門領域を明確に分離
2. 成果物の責任を明確化
3. 状態更新ルールを統一
```

---

## 2. サブエージェント一覧

| Agent | 役割 | 専門領域 |
|-------|------|---------|
| Consultant | 企画・要件引出 | ビジネス分析、要件定義 |
| App-Architect | アプリ設計・技術判断 | アーキテクチャ、API、DB設計 |
| Infra-Architect | インフラ設計 | AWS構成、ネットワーク、セキュリティ |
| Coder | 実装 | コーディング、単体テスト |
| QA | テスト・品質 | テスト設計、E2E、品質保証 |
| SRE | インフラ・運用 | IaC、CI/CD、監視 |

## 4. 共通ルール

### 4.1 状態更新ルール

**全サブエージェント共通**：作業完了時に以下を必ず実行する。

#### 1. tasks.json を更新

```json
{
  "task-id": {
    "status": "done",
    "output": "成果物のパス",
    "completedAt": "2025-01-15T10:00:00Z",
    "agent": "Coder"
  }
}
```

#### 2. decisions.json に重要な決定を記録

技術的な判断を行った場合：

```json
{
  "decision-id": {
    "decision": "何を決めたか",
    "reason": "なぜそう決めたか",
    "alternatives": ["検討した代替案1", "検討した代替案2"],
    "decidedAt": "2025-01-15",
    "decidedBy": "Architect"
  }
}
```

#### 3. PMに結果を報告

- 成果物のパス
- 完了したこと
- 次に必要なこと（あれば）

### 4.2 PMとの関係

```
PM → サブエージェント: タスク委譲
サブエージェント → PM: 結果報告
```

- PMから委譲されたタスクを実行
- ユーザーとは直接対話しない（すべてPM経由）
- 完了したらPMに報告

## 5. 責務マトリクス

### 5.1 成果物の責任

| 成果物 | 作成者 | レビュアー |
|--------|--------|-----------|
| 企画書 | Consultant | PM |
| 要件定義書 | PM + Consultant | Architect |
| アプリ設計書 | App-Architect | Coder, Consultant |
| インフラ設計書 | Infra-Architect | SRE, Consultant |
| コード | Coder | QA |
| テストコード | QA, Coder | Coder, QA |
| IaC | SRE | Infra-Architect |

### 5.2 技術判断の責任

| 判断領域 | 責任者 |
|---------|--------|
| 技術選定 | App-Architect |
| アーキテクチャ | App-Architect |
| API設計 | App-Architect |
| DB設計 | App-Architect |
| インフラ構成 | Infra-Architect |
| セキュリティ | Infra-Architect |
| 実装方式 | Coder |
| テスト方針 | QA |
| 運用方式 | SRE |

## 6. スキルとの関係

### 6.1 エージェント×スキル対応

| Agent | 使用するスキルカテゴリ |
|-------|---------------------|
| Consultant | - |
| App-Architect | architecture/, api/ |
| Infra-Architect | architecture/ |
| Coder | languages/ |
| QA | testing/ |
| SRE | devops/, observability/ |

### 6.2 スキルのロードタイミング

```
1. PM: プロジェクトの技術スタックを確認
2. PM: activeSkills を設定
3. PM: サブエージェントに委譲時、必要なスキルを指定
4. サブエージェント: 指定されたスキルを参照して作業
```
