## 責務

01文書4.6.1節・03文書3.8節（版1.3）が定めるとおり、06番は他のIPA成果物と異なり
**GZ2以前（リリース実施より前）**に生成する。「Zone3まで空である状態が正常」という
02文書4.2.1節の集合から06番は除外される（Zone3〜Zone4境界ではなく、Zone2の硬化完了に
合わせてより早く埋まる）。

| 文書 | 必須区分 |
|---|---|
| 06-01 移行計画書 | 条件付き必須（データ移行・既存リプレースを伴う案件のみ） |
| 06-02 移行手順書 | 条件付き必須（同上） |
| 06-03 受入テスト結果報告書 | 必須（GZ2のGO判定材料の一つ） |
| 06-04 リリース手順書 | 必須（リリース実施の直前に確定） |
